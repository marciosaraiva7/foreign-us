# Foreign US

Premium automotive care landing page for Foreign (FRGN) — South Florida, USA.

## Stack

- Next.js 16
- React 19
- Tailwind CSS 4
- TypeScript

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The root path redirects to `/en`, `/es`, or `/pt` based on browser language or the `NEXT_LOCALE` cookie.

## Environment

Optional:

```bash
NEXT_PUBLIC_SITE_URL=https://your-domain.com
```
